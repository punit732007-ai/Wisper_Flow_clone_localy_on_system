## 📖 Overview

**LocalWhisper Pro** is an ultra-fast desktop speech-to-text dictation suite for Windows. It runs quietly in your background, hovering a glassmorphic floating HUD on screen with live audio visualizer feedback.

Capture your voice anywhere with a single hotkey (default: `Ctrl + Space`), transcribe with **faster-whisper** (NVIDIA CUDA float16 GPU acceleration or CPU int8), and automatically clean, format, or translate your speech using local or cloud AI (Ollama, Groq, OpenAI, Gemini) directly into the active cursor position.

Now featuring an **interactive Theme Studio with 35+ handcrafted aesthetic styles**, real-time custom palette creator, multiple HUD layout presets, and custom wallpaper support!

## 🚀 Quick Start & Installation

### Option A: Run from Source

#### Prerequisites
- **Python 3.11 or 3.12** installed on Windows.
- Optional: NVIDIA GPU with CUDA drivers (for instant GPU inference).

#### 1. Clone the Repository
```bash
git clone https://github.com/punit732007-ai/Wisper_Flow_clone_localy_on_system.git
cd Wisper_Flow_clone_localy_on_system
```

#### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

#### 3. Run LocalWhisper Pro
```bash
python main.py
```
*(Or simply double-click `run.bat`)*

---

### Option B: Using Ollama for 100% Offline AI Post-Processing

1. Download Ollama for Windows from [ollama.com/download](https://ollama.com/download).
2. Open PowerShell or Command Prompt and download a fast model:
   ```bash
   ollama run llama3.1:8b
   # or ultra-fast compact models:
   ollama run qwen2.5:3b
   ```
3. Open LocalWhisper Pro Settings (⚙️) -> **"🧠 AI Refiners"** -> Select **Ollama** -> Choose your model -> Click **Save & Apply**.

## 💡 How to Access Themes & Customization

You can open the Themes Studio in 3 different convenient ways:
1. **Right-Click the Floating HUD**: Select **`🎨 Themes & Customization...`** from the context menu. You can also change the Layout Style directly from this menu!
2. **System Tray Icon**: Right-click the LocalWhisper Pro tray icon near your Windows clock and select **`🎨 Themes & Customization...`**.
3. **Settings Dialog**: Open Settings (⚙️) -> Go to the **`🎨 Appearance`** tab -> Select any theme directly from the dropdown or click **`✨ Open Themes & Customization Studio`**.

## 🔒 Architecture & Privacy

- **No Clipboard Overwrites**: LocalWhisper Pro types your refined text directly into the active window cursor (`pynput` / `SendInput`), keeping your Windows Clipboard History (`Win + V`) completely clean and private.
- **Offline First**: All audio stays on your local machine. Faster-Whisper runs locally on your GPU/CPU, and Ollama runs completely offline without sending any audio or text to third-party servers.
- **Dynamic Thread-Safe UI**: Uses queue-drained event loops ensuring 100% crash-free Tkinter performance on Windows.
